Meyar ERP 2 — 0.1.1

- Classic accounting interface with yellow, cream and gray tones.
- Separate internal module windows with minimize, restore/maximize and close controls.
- Each open window preserves its own date filter, search, page and page size.
- Filter/table area uses a 7:93 split; a 36 px filter minimum keeps controls usable in short windows.
- Compact zebra tables and bottom window tabs.

Download Meyar-ERP-2-Setup-0.1.1.exe and run it after closing Meyar.
The existing accounting database remains in the same application data directory.
This is an unsigned review build. Automatic updates are not enabled.
